拼贴艺术 · 设计说明

collage art · what changed

手法 · technique

  • 撕纸边：板块条与标签用 clip-path 撕口，配合 drop-shadow 让影子跟着纸边。
  • 和纸胶带：repeating-linear-gradient 斜条纹，压在纸片角上。
  • 微旋错落：-1.5deg ~ 1deg 随机旋转，刻意不对齐。
  • 混搭字体：衬线正文 + 等宽日期编号 + 无衬线标签，交替使用。
  • 纸面纹理：radial-gradient 斑点 + repeating-linear-gradient 横线，纯 CSS 无图片。

换掉了什么 · dropped

  • 统一卡片竖列，改为剪贴纸片：宽窄与旋转各不相同。
  • 四宫格指标，改为大小不一、错落旋转的贴纸。
  • 整齐一排的分类筛选，改为高低错开的标签贴纸。
  • 圆角与柔光，改为无圆角加硬偏移影 5px 5px 0。
  • 平滑渐变与毛玻璃，改为纯色硬边。
  • 温和刊物风（暖米+粉+墨），改为旧纸加炭灰硬边的手工剪贴。

保留的骨架 · kept

  • 手机屏 352 × 722，仅内容区纵向滚动。
  • 单行横向板块条：永不换行、不堆高，每项带数量角标，首项固定「⋯ 全部」，右缘渐隐遮罩。
  • 「⋯ 全部」浮层：3 列九宫格展示所有板块，点 tile 切换并关闭，点背景或「关闭」也能关。
  • 淡入上滑入场，逐条错开 60ms，并有 prefers-reduced-motion 关闭动效。
  • 原生 JS 控制浮层开关与板块切换，切换时选中项居中，条目重新错开入场。
  • 人物与文案：绥 / 沈砚 / 周野、四个指标、系统条与全部记忆条目一字未改。
