## 她给这份清单定的调子

> **朋友圈不是番外。它本身就是剧情的一部分。**

## 清单

1. **支持 User / Char 双方发朋友圈**，自定义正文、标签和可见范围。

2. **被屏蔽的角色不能直接点赞、评论或回复**，但共友可以看到、评论、传话，甚至把内容透露给角色，**形成信息差**。

3. **内置动态 NPC / 共友关系网**，会自然出现室友、同学、同事、网友等人物，并持续参与评论区互动。

4. 支持**评论、楼中楼、点赞、NPC 回复、代传话、删除指定评论**。

5. **User 和 Char 都可以修改朋友圈**。修改后显示「已修改」，并保留**最新一次修改前的正文**。

6. **修改、删除朋友圈都会有影响**。角色可能真看过、没看见、故意诈你，或明明看见却装不知道。**用户这边同理。**

7. 支持 **STORY 事件链**，一条朋友圈可以经过评论、聊天，再延续到新的朋友圈，并**引用原动态内容**。朋友圈持续发展而不是每轮失忆。

8. 支持**转发朋友圈**。User 可以写转发正文、标签、可见范围；**Char 也可以主动转发**。

9. **Char 可以拥有隐藏的发帖动机**，比如嘴硬、试探、等你主动、想被安慰等，并在之后的聊天里继续发展。这类特殊的隐喻帖子，表面上可能只是：「今晚月亮挺亮。」但内部可能其实是：想让 User 主动找他／想确认 User 在不在意／等一句安慰／故意发给 User 看／嘴硬不肯直接说／试探 User 的反应，如果 User 仅点赞 or 甚至无互动，Char 就会在聊天里面闹了（bushi）

10. **朋友圈会主动跟随聊天内容**。吃东西、出门、吐槽、照片、情绪、玩笑等日常话题，都可能自然延伸成新的动态。

11. **不同事件还有独立通知**：Char 发动态、修改动态、点赞评论、NPC 评论/回复、仅你可见、偷偷屏蔽你等都会有对应提示。

12. **支持生图插件**，如果同时打开了新月生图插件那么就会同时返回文本图片和生图。支持重 roll / 修改提示词 / 存图。
